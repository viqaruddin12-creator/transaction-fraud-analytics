# transaction-fraud-analytics
Business intelligence report built with Power BI to visualize transaction anomalies, analyze high-risk behavior, and mitigate financial loss.
# Transaction Fraud Analytics Dashboard




 
## ✨ Key Features & Insights
* **Anomaly Detection:** Identification of suspicious transaction spikes and pattern deviations.
* **Risk Score Metrics:** Categorization of high-risk users and transaction types.
* **Interactive Filtering:** Dynamic analysis across time periods, regions, and transaction channels.

## 🛠️ Tools Used
* **Power BI Desktop** (Data Modeling, DAX, Visualizations)
* **SQL / Excel** (Data Cleaning & Preparation)
